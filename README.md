# NetFlow ISP — 3 Company Dashboard

Responsive static ISP management dashboard for GitHub Pages.

## Features
- 3-company management
- Customer/user management
- Package rates, user fees and user profit
- Billing
- Expenses and staff salaries
- Excel/CSV import
- Reports
- Customer portal mock UI
- Local browser storage (no server required)
- Responsive layout for laptop, tablet and mobile

## GitHub Pages
1. Create a GitHub repository.
2. Upload **all files in this folder** with `index.html` in the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)`, then Save.
6. Open the generated GitHub Pages URL.

## Important
This is a frontend/local-data dashboard. Data is stored in the browser's `localStorage` and is not shared between devices. Excel import uses the SheetJS library loaded from jsDelivr.
